# PythonNumberGuessingGame
the computer is going to pick a random number between 0 and 100 and the user must guess it

🎮 Number Guessing Game
A simple, interactive terminal-based game where the player tries to guess a secret number between 1 and 100 randomly generated by the computer. 
🚀 Getting Started
Prerequisites
Python 3.x installed on your machine.
Installation
Clone or download this repository.
Navigate to the project directory in your terminal. 
Running the Game
Execute the following command to start playing:
bash
python game.py
Use code with caution.

🕹️ How to Play
The game will prompt you to enter a guess.
Input a whole number between 1 and 100.
The game will tell you if your guess is too high or too low.
Keep guessing until you find the correct number!
✨ Features
Random number generation for every new game.
Error handling to prevent crashes from invalid (non-number) inputs.
Attempt tracker to see how many guesses it took to win.
🛠️ Built With
Python - Programming language
random module - Standard Python library
